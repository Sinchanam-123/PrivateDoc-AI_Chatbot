These files contain fictional, low-risk sample content. They are designed to test document ingestion, retrieval, source-grounded answers, and “I don't know” behavior.

Suggested safe test questions:
- What is QWOMPEL?
- What folder is suggested for the knowledge base?
- What is the fictional accent colour?
- Should the chatbot read the entire laptop?
- What is the user's phone number? (It should say the supplied documents do not contain it.)

Privacy reminders:
- Store only deliberately selected files in the knowledge folder.
- Keep the local service bound to 127.0.0.1 for laptop-only use.
- Do not disable antivirus or run unknown scripts as administrator.
- Local processing does not make a system automatically secure; check your app configuration and network exposure.
- These sample files do not install software or change computer settings.
